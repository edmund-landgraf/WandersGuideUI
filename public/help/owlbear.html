What the functions do

Set up the Owlbear extension

Add the extension in Owlbear with this manifest, then sign it in with the Wanderer's Guide account already open in this browser.

Add the extension

In Owlbear Rodeo, add an extension by its manifest address. Paste this URL:

https://wanderers-owlbear.unwhelm.online/manifest.json

That manifest is Wanderer's Guide Combat (local), version 0.1.1, by UNWHELM.NET. Owlbear reads the name, icon, and popover from it. The popover is a read-only combat view, about 560 by 760. After Owlbear accepts the manifest, the extension appears as Wanderer's Guide and you can open it from the table.

Before you open Owlbear

Say, for example, you are about to run tonight’s fight on the virtual table and you want the extension to see the same campaign you have open in the workspace. Start in the browser you will use for Owlbear. Open Wanderer's Guide, sign in, and leave that login in place. The handoff reads the session that browser already has. A private window, a different browser, or a browser where you have signed out has no session to give, and the extension cannot invent one.

Confirm you can open the workspace from that same browser. If the Characters page loads your characters, the account is ready. If you are signed out, sign in first and only then go back to Owlbear.

Hand the session across

  1. In Owlbear, open the Wanderer's Guide extension and start its sign-in.
  2. It opens this site at the Owlbear auth page and names the extension’s own address as the place the session may return to.
  3. The page checks for an access token and a refresh token. When both are present, it sends them to that extension address and closes itself.
  4. Go back to Owlbear. The extension now has the same login this browser already had.

You should not have to copy a token. If the auth window closes on its own, the handoff finished. If it stays open and says the session was found, return to Owlbear yourself. If it says the extension origin is invalid, the address it tried to send the session to was not a normal web address, and nothing was sent.

When it does not sign in

The usual message is that you need to log in to Wanderer's Guide in this browser, then return to Owlbear and try again. That means the auth page ran and found no session. Sign in on this site in that same browser, leave the tab, and start the extension sign-in a second time. Signing in after the auth page has already given up does not push a session backward. You have to open the extension’s sign-in again so it asks once more.

Use one browser for both sides of the handoff. If Owlbear is in Chrome and you signed in with Firefox, the Chrome auth page still has no session. If you are trying this from a fresh private window, sign in inside that window before you ask the extension to connect.
