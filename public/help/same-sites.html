Why the sites look the same

amba.wandersguide.site and wanderersguide.app show the same character builder, so the pages look almost identical.

On amba the account menu adds Experimental beside Wanderer's Guide, Community, Support, and Legacy Site. That entry is the workspace: campaigns, encounters, and combat.

The extra work sits under the covers on this host. Campaigns, encounters, combat, and the calls that join a character, load the party, and save the fight run here. wanderersguide.app does not run those calls yet. Import the character into this workspace when you want it on a campaign or in a fight.
